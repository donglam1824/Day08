# Retrieval support chunks

## Refund and return evidence

Refund evidence is required when a buyer asks for a return or refund. The buyer should provide photos, videos, screenshots, order ID, invoice, and a clear explanation of the problem. This evidence helps support a refund request and a return refund evidence policy review.

## Return refund evidence policy

The return refund evidence policy states that buyers must keep proof of the issue, including damaged item photos, delivery confirmation, and communication records with the seller. Good evidence improves the chance that the refund request is approved.

## Payment methods

Shopee supports many payment methods such as cash on delivery, credit card, debit card, bank transfer, e-wallet, ShopeePay, and other payment methods. Buyers can review available payment methods before placing an order.

## Order tracking guide

The order tracking guide explains how to check order tracking status, delivery progress, shipment updates, pickup confirmation, and delivery success. Sellers and buyers can use this order tracking guide to follow the package.

## Seller listing regulations

Seller listing regulations require accurate product descriptions, clear images, valid specifications, and honest listing details. Sellers must follow seller listing regulations and provide truthful information to protect buyers.

## Policy for refund request

A refund request should include the reason for the refund, relevant evidence, and the order details. The system reviews the refund request and checks whether the evidence is sufficient.

## Return policy summary

The return policy allows buyers to return items when the product is damaged, wrong, defective, or not as described. The return process requires a valid reason and supporting evidence.
